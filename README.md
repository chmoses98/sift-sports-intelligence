# Sift live-quote feed

Generated by `.github/workflows/live-quotes.yml` from Kalshi public market data (read-only). Force-pushed; no history is kept. `index.json` `sport_status` says, per sport, whether its publication was current (CURRENT_SLATE), legitimately quiet (NO_CURRENT_GAMES), stale or unreadable, and whether its games are in this feed: an excluded sport has no game files here (never stale quotes presented as current). `status` describes the published sports; when nothing trustworthy can be published the previous feed stays.
