# SIFT v4 (phone-first preview)

v4 is the phone-first SIFT experience approved in `design/mobile-v3-redesign`, built on the real app: the same published
boards, research documents and Kalshi quotes, through the same data layer. It is **opt-in**: nothing changes for the
default (SIFT 2.0) or classic interface unless v4 is asked for.

## Opening it

| How | What it does |
| --- | --- |
| `#/v4` | Opens v4 directly (any build). |
| `#/?ui=v4` | Remembers v4 in this browser (`localStorage` key `sift.ui`); classic root addresses then open v4. |
| `#/?ui=default` | Forgets the choice (back to the build's interface). `?ui=sift2` / `?ui=classic` switch away. |

Everything lives in `src/v4/` and is one lazy chunk; its CSS is scoped under `.v4`, so it cannot reach the other
interfaces. Fonts (Geist Sans, Sora) are loaded only by that chunk.

## What is in milestone 1

- **Shell** (`V4Root.tsx`): five tabs (Home, Games, Props, Signals, Board) on React Router, safe-area aware, one sheet host.
- **Home** (`Home.tsx`): league selector, date strip, Following / All / Live / Signals, featured game, live / upcoming /
  final groups, compact rows, signal chips.
- **Games** (`Games.tsx`): the whole day by league with a status filter.
- **Game Command Center** (`Game.tsx`): scoreboard and Live / Matchups / Players / Markets.
- **Research sheet** (`ResearchSheet.tsx`): one published opportunity: why, price against the model, strongest published
  risk, then evidence / risks / prices / sources on request.
- **Props, Signals, Board**: honest hand-off screens linking to the current SIFT 2.0 screens (not part of this milestone).

## What is real, and what is not

| Element | Source | State |
| --- | --- | --- |
| Games, start times, lifecycle (upcoming / in play / awaiting result / final / postponed) | Published boards via `useAllOpportunities` / `gameRows` | Real |
| Final scores | `extensions.result` of the game's research document | Real, only when the publication reports both numbers |
| Live score, clock, period, down and distance, plays | **Not in the published contract** | Unavailable: said so on the card, the row and the Live tab; nothing is estimated |
| Team logos, venue photograph, team colours | Hero system (`resolveHero`), verified venue tiers, committed logos | Real; branded graphic when no verified photo exists |
| Player photos | `broadcastPlayerPhoto` (identity-checked, reviewed) | Real; team crest when none is approved |
| Records | Verified league schedule (NFL) | Real where available |
| Matchup edges, game scripts | Existing NFL insight layer (`matchupInsights`, `gameScripts`) | Real for NFL; other sports say they are not published |
| Player projections | `propCards` with the projection-authority layer (one projection per metric) | Real for sports with projections; shown beside, never merged with, the Kalshi line |
| Kalshi markets, asks, freshness | Publication markets overlaid with live quotes (`overlayMarket`) | Real; quotes older than 30 min are marked stale, capture times shown |
| Research signals | Published opportunities (`Opportunity` contract) | Real; pregame research is labelled frozen once a game starts |
| Following | Local list in `localStorage` (`sift.v4.follow`) | Device-only |

v4 never says "bet": the sheet names what the publication states (its side, price, fair range, fee-aware break-even, its
own upper limit price) and says it is research only.

## Reviewing it

```
npm ci
npm run dev
# open http://localhost:5173/sift-sports-intelligence/#/v4   (check the printed URL)
```

Resize to 390 x 844, 375 x 812 and 375 x 667 (or use device mode). Use `#/v4/game/nfl/<event id>` for a game; every game
row on Home and Games links there.

### On an iPhone

There is no hosted preview. To open it on a phone on the same Wi-Fi:

```
npm run dev -- --host
# on the phone: http://<computer LAN IP>:5173/sift-sports-intelligence/#/v4
```

or deploy a branch build to any static host with the Pages base path. Real iOS Safari, VoiceOver and device-performance
testing are still required before production approval; they have not been done.

## Tests

- `tests/v4.test.tsx`, `tests/v4ResearchSheet.test.tsx`: UI mode, gate, calendar and filter logic, the research sheet's wording.
- `e2e/v4.spec.ts` (needs `npm run build:e2e`): shell, Home, Games, game tabs, the three phone sizes (no overflow, 44 px
  controls, no clipped names, no text under 12 px except tab labels), reduced motion, back behaviour, hand-offs, axe, the
  default interface unchanged. Set `V4_SHOTS=<dir>` to save screenshots of the real app.
