A live sports companion first. Graphite ground, light used the way a stadium uses it, one inverse selected state, and numerals set like a scoreboard. Colour keeps its meaning; team colour lives in the lighting, never in the chrome.

Sora carries numerals and display: wide, athletic, with tabular figures, so scores and prices align and never jitter. Geist carries everything that is read: names, labels, notes. Four weights. Sentence case; small capitals only for the single LIVE state.
