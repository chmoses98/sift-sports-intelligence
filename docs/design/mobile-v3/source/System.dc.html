Research integrity, carried over unchanged

Simulation shares are labelled as shares, not calibrated probabilities, on every script view.
A gap is never called an edge. The model figure, its range and the worst case sit beside the price, with the research-only warning.
Quote, model and lineup freshness stay separate, and a stale or unavailable input is named in the Sources tab.
No score, clock or period is invented. In-play games show their start time and a frozen-research state until the publication supplies more.
Missing values say why. “No model price published for spreads” replaces an empty cell or a zero.
Copy for ChatGPT stays one tap from every signal, and prices refresh before the packet is built.
