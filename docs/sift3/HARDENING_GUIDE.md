## Rules for every hardening worker
- Work only in your own git worktree (your brief names it) on your own branch off `origin/claude/sift3-impl`; `cd` there first and run every command from it. Symlink `/home/user/sift-sports-intelligence/node_modules` if missing. **Commit and `git push -u origin <branch>` after every meaningful step, at least every 20 minutes**: the container restarts without warning and unpushed work is lost. If you were resumed after a restart, first read `git log`, `git status`, re-run the gates, then continue.

- Dev server on your own port (`npx vite --port <port> --strictPort &`); Chromium for Playwright: `SIFT_CHROMIUM=/opt/pw-browsers/chromium-1243/chrome-linux64/chrome`; run specs with `V3_PROJECTS=v3-phone V3_PORT=<port> npx playwright test -c playwright.v3.config.ts --workers=2 <specs>`. WebKitGTK (real WebKit engine, not iOS Safari): `WK_PORT`/`WK_HARNESS_PORT` env vars avoid port clashes with other workers (`scripts/v3-qa/start_driver.sh`, `scripts/v3-qa/*.py`).
- Real-document specs read a disk cache of captured published documents on a fixed clock. Caches are NOT mergeable across families (different capture instants). Copy exactly the cache your brief names into your worktree as `.v3-feed-cache` (it is gitignored). Never mix caches. The committed, offline fixtures bundle (`fixtures/real`, branch `claude/sift3-h-fixtures`) replaces the cache once it is merged: specs then select a family (`useRealFeeds(page, { family })`) and no `.v3-feed-cache` is needed (see `fixtures/real/README.md`); until it is merged into your branch keep using the cache.
- Honesty: never invent data; unavailable data is "—" or a labelled state with its reason; real vs sample vs captured data is always distinguishable; no visible freshness/age/timestamp on prices (quote gate only); model numbers only where the approval ledger allows.
- Gates before every report: `npx tsc -b`, `npx eslint src/v3 tests/v3 e2e scripts`, `npx vitest run`, and every v3 Chromium spec your change can affect (sample-data suites: `e2e/v3.spec.ts e2e/v3-foundations.spec.ts e2e/v3-saved.spec.ts e2e/v3-a11y.spec.ts e2e/v3-quotegate.spec.ts e2e/v3-hit-targets.spec.ts`), WebKitGTK `scripts/v3-qa/journeys.py`. Update an existing assertion only when the owner's decision intentionally changed behaviour, and say which.
- Report only verified facts: what changed, evidence (commands and counts), what you could not verify, and decisions that genuinely need the owner. No speculation presented as fact.
